# University Management System

A console-based University Management System developed in C++ as an Object-Oriented Programming (OOP) project. The application provides essential tools for managing academic records through a simple menu-driven interface.

## Features

- Student Management
- Faculty Management
- Course Management
- Student Enrollment
- Attendance Tracking
- Marks Management
- Fee Management
- Admin Login System

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- File Handling
- Standard Template Library (STL)

## Data Storage

The system stores data in the following files:

```text
students.txt
faculty.txt
courses.txt
enrollments.txt
attendance.txt
marks.txt
fees.txt
users.txt
```
